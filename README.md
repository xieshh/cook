# 今天吃什么 · 两个人的家常菜

内置 100 道家常菜谱（含精确配比和做法），支持关键词搜索、分类筛选、随机推荐、收藏、标记做过、买菜清单、按食材找菜、自定义拿手菜，两人数据通过坚果云自动同步。纯静态网页，微信里点开即用，0 费用。

## 一、部署到 GitHub Pages（一次部署，永久使用）

1. 在 GitHub 上新建一个仓库（名字随意，如 `zycp`，勾选 Public 或 Private 都可以）
2. 在项目文件夹打开终端，执行：

```bash
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/你的用户名/zycp.git
git push -u origin main
```

3. 网页操作：进入仓库 → Settings → Pages → 在 Build and deployment 的 Source 选 `Deploy from a branch`，Branch 选 `main` 和 `/ (root)` → Save
4. 等 1-2 分钟后访问 `https://你的用户名.github.io/zycp/`，用微信打开这个链接，就是你们的专属菜谱应用
5. 想让两人更好找：把链接发到微信聊天里，右上角「···」→ 添加到桌面，或者置顶聊天

## 二、云端同步配置（两人共享收藏/做过记录）

1. 注册一个免费坚果云账号（电脑网页或手机 App：https://www.jianguoyun.com ，手机号即可）
2. 登录网页版 → 右上角头像 → 账户信息 → 安全选项 → 「添加应用」→ 名称随意（如 zycp），会生成一个**应用密码**（注意：不是登录密码）
3. 用微信打开应用 → 「我的」页 → 云端同步：
   - WebDAV地址：`https://dav.jianguoyun.com/dav`（默认已填）
   - 账号：你的坚果云登录邮箱
   - 密码：**刚才生成的应用密码**
   - 文件路径：`zycp/data.json`（默认已填）
4. 点「保存并同步」，状态显示「同步成功 ☁️」即可

女朋友那边只要也填同一个账号，打开就会拉到最新数据。两人任何一方收藏、标记、加菜，另一侧打开时自动同步。

## 三、本地预览（可选）

```bash
cd 项目目录
npx serve .
```

浏览器打开提示的地址即可。

## 四、文件说明

| 文件 | 说明 |
|---|---|
| index.html | 页面结构 |
| styles.css | 样式（深浅色模式） |
| app.js | 全部交互逻辑 + 坚果云同步 |
| recipes-data.js | 100 道内置菜谱数据（想加菜可改这里） |

## 常见问题

- **同步失败**：检查应用密码是否填错、路径是否正确、网络是否正常；首次使用请先「保存并同步」测试
- **数据安全**：所有数据存在各自手机的浏览器本地 + 你的坚果云，不会上传到任何第三方
- **想删数据**：「我的」页有清空本地数据按钮
